# Data Dictionary

All data is synthetic (generated by `generator/generate_dataset.py`, seed 42). Currency is INR.

## customers (600 rows)
| Column | Type | Description |
|---|---|---|
| customer_id | INT PK | Unique customer id |
| customer_name | VARCHAR(80) | Randomly generated Indian full name |
| city | VARCHAR(40) | One of 11 cities (weighted by size) |
| state | VARCHAR(40) | State of the city |
| signup_date | DATE | Account creation date |
| referred_by | INT FK NULL | `customer_id` of the referrer (about 22% of customers); self-reference |

## product (30 rows)
| Column | Type | Description |
|---|---|---|
| product_id | INT PK | Unique menu item id |
| product_name | VARCHAR(80) | Menu item |
| category | VARCHAR(40) | Main Course, Rice, South Indian, Street Food, Starters, Breads, Dessert, Beverages, etc. |
| description | TEXT | Short description |
| cost_inr | DECIMAL(8,2) | Cost to the restaurant |
| price_inr | DECIMAL(8,2) | Menu price (always >= cost) |

## orders (4,000 rows, Jan 2025 - Sep 2026)
| Column | Type | Description |
|---|---|---|
| order_id | INT PK | Unique order id (chronological) |
| customer_id | INT FK | Who ordered; never before their `signup_date` |
| order_date | DATE | Date placed |
| payment_method | VARCHAR(20) | UPI, COD, Credit/Debit Card, Wallet |
| tip_inr | DECIMAL(8,2) | Tip to delivery partner |
| rating | TINYINT NULL | 1-5; about 14% NULL (not rated) |
| review_text | TEXT NULL | Short review, consistent with rating |

## order_item (11,977 rows)
| Column | Type | Description |
|---|---|---|
| order_item_id | INT PK | Unique line id |
| order_id | INT FK | Parent order |
| product_id | INT FK | Menu item |
| quantity | TINYINT | 1-3 |
| unit_price_inr | DECIMAL(8,2) | Price at order time (snapshot) |

## Built-in patterns in the generator
- Weekends weighted 1.35x; Oct-Nov (Diwali season) 1.4x; March (Holi) 1.2x; Jul-Aug 0.9x.
- 120 "loyal" customers account for about 45% of orders.
- Orders have 1-5 distinct items.
